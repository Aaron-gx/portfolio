### 维护

索引由 `generate.py` 生成。新增仓库后，在 `generate.py` 的 `CATEGORIES` 里登记名字和一句话简介，然后运行：

```bash
python generate.py
```

脚本会拉取最新的仓库元数据（公开/私有、语言、更新时间），重新生成统计行并覆盖本 README。
